# ✋ Hand Tracking System

A real-time hand tracking web application built using **MediaPipe**. It uses the webcam to detect hands and display their **hand landmarks** directly in the browser.

## 🚀 Live Demo

👉 **[Live Demo](https://niharikaaruna-naidu1229.github.io/HandGesture/)**

Allow camera access when prompted and show your hand in front of the webcam.

## ✨ Features

* Real-time hand tracking
* Supports up to 2 hands
* Displays hand connections and landmarks
* Runs directly in the web browser
* No installation required for the live demo

## 🛠️ Technologies

* MediaPipe Tasks Vision
* JavaScript
* HTML
* CSS
* Web Camera API

## ⚙️ How It Works

```text
Webcam
   ↓
Video Capture
   ↓
MediaPipe Hand Landmarker
   ↓
Hand Detection
   ↓
21 Hand Landmarks
   ↓
Real-Time Visualization
```

## ▶️ Run Locally

1. Clone the repository:

```bash
git clone https://github.com/niharikaaruna-naidu1229/HandGesture.git
```

2. Open the project in VS Code.

3. Open `index.html` using Live Server.

4. Allow camera access.

5. Show your hand in front of the webcam.
